# avito-feed

Фид для автозагрузки объявлений на Авито (недвижимость).

- `ads/*.json` — по одному файлу на объявление
- `config/common_fields.json` — общие для всех объявлений поля (контакт, телефон, способ связи)
- `config/categories.json` — схема полей по категориям (продажа/аренда квартир, домов, участков, коммерции)
- `build_feed.py` — собирает `feed.xml` из всего вышеперечисленного
- `feed.xml` — итоговый фид, на него настроена автозагрузка в личном кабинете Авито

Публичная ссылка на фид: `https://raw.githubusercontent.com/esstsu-bot/avito-feed/main/feed.xml`
